# Implementation Plan

## Overview
Build Graveyard of Ideas in layers: pure domain logic first (cheap, GPU-free, property-tested), then persistence, then the 3D world, tombs and books, then the foundation of the haunted skin, the keeper's voice and the comfort code (tasks 11.1 to 11.3), then the grimoire and burial (which use only that skin and voice), the resurrection sequence, and the cinematic rework (task 13). After task 13 the order is: the book of the risen (8.1), the menu (9.1), the plain mode (9.2), the entrance and atmosphere steps with their checkpoint (tasks 11.4 to 11.11), the sigil tasks (12.1, 12.2) and polish (10.1 to 10.3). Each top-level task is meant to be run in its own Kiro session and committed separately.
