# Hackathon constraints (Kiroween 2026, Costume Contest)

- Submission ends December 4, 2026, 2:00 pm Pacific Time. Project must be newly created after October 30, 2026; disclose any pre-existing work.
- The /.kiro directory must stay committed. Never add it to .gitignore.
- Repository public, with an open source license visible on the repo page. All source code, assets and instructions must be in the repo.
- The app must be built with Kiro and the write-up must explain how (specs, steering, hooks, property-based testing, etc.).
- Demo video under 3 minutes, public on YouTube, showing the app working on its target device; no copyrighted music or third-party trademarks.
- The haunted theme must enhance the function (the tomb contains the project; resurrection is a real action).
- All submission text in English.
