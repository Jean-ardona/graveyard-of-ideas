# Graveyard of Ideas

A first-person 3D night graveyard for your abandoned projects. Each resting project is a small book in a tomb; resurrect it with a realistic first step and watch it leave.

Built for Kiroween 2026 (Costume Contest) with Kiro. See `.kiro/` for steering, specs and the playbook in `docs/`.
